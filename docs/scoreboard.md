# SN2-Acoustics の到達度（ポイント）

各項目に「ゼロ点の基準」（何もしない場合）と「目標」（最低限の指標＝定番の手法や、専門家を全員動かす一番良い方式の値）を置き、今の値がその間のどこにあるかで採点しています。目標に届けば満点です。
計算式と数値は `tools/scoreboard.py` にあり、新しい結果が出たら書き換えて `python tools/scoreboard.py --md` で更新します。

  点 = 配点 × clip((今の値 − ゼロ点の基準) / (目標 − ゼロ点の基準), 0, 1)　（時間は log10 で）

## 伸びしろの大きい項目（あと何点取れるか）

- **2 次元の入力（画像など）のグレインで同じ組み立てができるか（1D の 3 つの目標を満たした課題の割合）**（2D）: あと 5.0 点
- **推論の速さ（µs/入力、GPU、まとめて流す。小さいほど良い）**（効率）: あと 3.2 点
- **1 グレインの学習時間（秒、GPU。小さいほど良い）**（効率）: あと 1.9 点
- **後から 1 人足したときの全体の正解率・順序課題（5 人・20 クラス、%）**（組み立て）: あと 0.7 点
- **振り分けの正解率・順序課題（上位 1、%）**（振り分け）: あと 0.6 点
