# 実験10「記憶の固定化」計画（2026-11-02、持ち主の確認待ち）

前の計画案（[到達点B_記憶の固定化_計画案.md](到達点B_記憶の固定化_計画案.md)）を、実験08 のプログラムを読んだうえで具体にしたもの。

## 1. 何を確かめるか（ひとことで）

実験08 では、新しい専門家を「付け足すだけ」（古い部分は一切さわらない）で足せた。これは**短期の記憶**にあたる。
代わりに、付け足すたびに

- 古いクラスが 1.5〜2.8 点下がる（服の写真で 83.4 → 81.2%、84.6 → 81.8%）
- 新しい人への振り分け（受付）が 85〜93% どまり
- 新しい人のための「薄い板の窓口」の分だけ計算が増える（FFT 5 回）

という「つぎはぎ」の跡が残る。

実験10 では、付け足した系を**お手本（先生）**にして、受付係（= 共通の前段）と各専門家の後段を**まとめて少しだけ学び直す**（= 長期の記憶へ移す）。寝ている間に記憶を整理するイメージ。つぎはぎの跡が消えるか、そのとき何を失うか（取消・学び直しの手間）を測る。

## 2. しくみの絵

```
足す前      : 絵 → 前段(板8) → 受付の窓(4人) → 選んだ1人の後段(板6) → 答え
付け足した系: 絵 → 前段(板8) → 受付の窓(4人) ＋ 薄い板の窓口(新人用) → 後段(板6)×5人
固定化した系: 絵 → 前段'(板8) → 受付の窓(5人)                      → 後段'(板6)×5人
```

固定化すると、新人用の薄い板の窓口が要らなくなる（計算が FFT 5 回減り、足す前と同じ形に戻る）。

## 3. 比べるやり方（固定化の 3 通り + 比べる相手）

Sin-CNN3 の知見（板を混ぜると壊れる・古い物を混ぜないと忘れる）から、どれも「今の板から出発して短く学び直す」「お手本か古いデータを必ず混ぜる」形にする。

| 名前 | 中身 | ねらい |
|---|---|---|
| **K1 前段だけ** | 前段'（5 人用の窓）だけをお手本つきで学び直す。後段は固定 | いちばん安い。ただし前段が変わると後段への光が変わり、後段が合わなくなるおそれ（前のスレッドの心配）。それがどのくらいかを測る |
| **K2 前段 + 後段（本命）** | 前段' と 5 人の後段' を一緒に、お手本の答えに合わせて学び直す（蒸留）。古いデータは 1 割 + 担当なしの絵 | 前段を動かしても後段がついてくる。古いデータが少なくても忘れにくいはず |
| **K3 お手本なし** | K2 と同じ形・同じデータで、正解のラベルだけで学び直す | 「お手本」がどれだけ効いているかを見る対照 |

比べる相手（同じ課題・同じ seed）:

| 比べる相手 | 意味 | 数字 |
|---|---|---|
| 付け足しただけ（実験08 の thin・古いデータ 1 割 + 下駄） | 固定化しない場合。お手本そのもの | 実験10 の中で作り直す（実験08 は学習済みを保存していないため） |
| 最初から 5 人そろって学習（実験07 の前段 8 + 後段 6） | 「つぎはぎなし」の理想。固定化のゴール | 実験07 の数字（服 83.4 / 82.9%、合成 83.5%） |
| 1 本で全データを学び直す（実験06） | 専門家に分けない場合 | 服 84.5 / 84.6%、合成 69.0% |

## 4. 物差し（何を測るか）

1. 全クラスの正解率（上位 1 人）
2. **古いクラスの正解率**: 足す前（83.4 / 84.6%）まで戻るか ← いちばん見たい
3. **新しい人の受付の正解率**: 最初からいた人と同じくらい（89〜96%）まで上がるか
4. 計算量（FFT 回数。固定化すると新人用の窓口の分が減る）
5. **取消**: 固定化した系から新しい人を外したとき、古いテストの答えが足す前とどれだけ一致するか（実験08 は 100% 一致）
6. 学び直しにかかった時間と使ったデータの量（1 本で全部学び直す場合と並べる）

課題: 服の写真 2 通り（似た服を同じ人に / 別々に）+ 合成 4 課題。3 seed、平均 ± 標準誤差。

## 5. 見込み（予想）

- K2 で古いクラスは 1〜2 点戻り、新しい人の受付も上がって、「最初から 5 人で学習」（83 点前後）に近づくと予想。
- K1 は後段が合わなくなって、かえって下がるかもしれない。
- 取消は、固定化した系では 100% にはならない（前段が変わるため）。ただし 6. の「決めてほしいこと」のとおり、固定化の前の系を保存しておけば元に戻せる。

## 6. GPU の見込み

- 実験08 の実測: 服 1 seed 17〜20 分、合成 8〜23 分。
- 固定化の学び直しは 1 回あたり後段の学習の数倍（前段 + 後段 5 人を一緒に通すため）。お手本の答えは最初に 1 回だけ計算して使い回す。K1〜K3 の 3 通りで 1 seed あたり 30〜40 分の追加。
- 合計: 服 2 課題 × 3 seed × 約 1 時間 + 合成 3 seed × 約 40 分 ≒ **8 時間分**。GPU 2 枚に分ければ**半日ほど（4〜5 時間）**。
- 共通の待ち行列に課題ごとの 3 行（sweep10a 合成・10b 服 同じ・10c 服 別）で予約。PC が重くならないよう、バッチを大きく、毎ステップの表示をしない（CLAUDE.md）。
- 予約の前に、この環境の CPU で合成課題を短いステップで動かしてプログラムの誤りを確かめる。

## 7. この後（結果しだい）

- うまくいけば: 2 人続けて足してから固定化する（「たまったら」の本来の形）。何を長期へ移すか（よく使われた人だけ等）の選び方。
- だめなら: 古い前段を残して新しい前段を並べる案（計算は増える）。

## 8. 決めてほしいこと

1. この計画（K1〜K3、服 2 + 合成、3 seed、GPU 約 8 時間分）で進めてよいか
2. 固定化した後の「取消」をどう考えるか:
   - (おすすめ) 固定化の前の系を保存しておき、取消は「保存から戻す」で完全に守る。固定化した系そのものから外したときの一致率は物差しとして測るだけ（学習する数は 4 千個ほどで、保存は数十 KB）
   - 固定化した系そのものでも外せば元どおり、を守る（学び直しに強い縛りが要り、効果が小さくなりそう）

## 9. 持ち主の決定（2026-11-02 12:23）

- 3 通り（K1〜K3）ともやる。GPU は共通の待ち行列に予約して、のんびり待つ。
- 取消は「分けて管理」: 固定化の前の系を残しておき、取り消すときはそこへ戻す。外しても元どおりのまま融合できる場合（戻さずに済む場合）があれば、そのときは融合する。
- 実装の細部: お手本合わせは、受付の点数を KL（重み 1）、各後段の担当の生の点数を二乗誤差（重み 0.1）で合わせる。固定化の学習率 0.005（cosine）、ステップ数は最初の学習と同じ（合成 1500、服 3000）。条件は experiments/sweeps/sweep10a〜c.sh。
